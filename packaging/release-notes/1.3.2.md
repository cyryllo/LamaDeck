# LamaDeck 1.3.2 — small fixes in the chat

Fixes found while making the new screenshots for the user guide.

### Fixed
- **Links in answers were hard to see** — a link the model wrote (e.g. to the diagram it drew in
  ArchFlow) was dark blue on the dark background. Links now have the same light colour as the
  sources under the answer.
- **LaTeX arrows** — some models write routes as `A $\rightarrow$ B`. The chat now shows `A → B`
  (also ×, ≈, ≤, ≥ and a few other symbols), in the window and in the browser. *Copy* still copies
  exactly what the model wrote.
- **Chat in the browser on a phone** — with four buttons next to it, the question box was only a
  few letters wide. It now takes the whole row, with the buttons and *Send* below it.
- **MCP server window** — the *Certificate (CA)* row was cut off at the bottom.

### Docs
- The user guide shows the current version: all screenshots are new, and the MCP chapter has
  screenshots of the server window, a diagram drawn in ArchFlow and the approval window.
- Clicking a heading in the guide's contents no longer lands next to it.

### Install
- **Debian / Ubuntu**: `sudo apt install ./lamadeck_1.3.2_all.deb` — later updates come with
  `apt upgrade`.
- **Other distributions**: download `LamaDeck-1.3.2-x86_64.AppImage`, make it executable and run it.
