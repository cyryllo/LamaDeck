LamaDeck APT repository

Debian / Ubuntu repository of LamaDeck. Installing the .deb from the GitHub releases adds it automatically. To add it by hand:

sudo curl -fsSLo /usr/share/keyrings/lamadeck-archive-keyring.gpg https://cyryllo.github.io/LamaDeck/apt/lamadeck-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/lamadeck.sources https://cyryllo.github.io/LamaDeck/apt/lamadeck.sources
sudo apt update
sudo apt install lamadeck
